# Minting Your Own Tokens

Hands-on material for **Minting Your Own Tokens: The Server Side of the Token Economy**, a [KubeCon + CloudNativeCon North America 2026 tutorial](https://bit.ly/kcna26-suraj-nilekh).

Learn to serve large language models with vLLM on Kubernetes, from one GPU to tensor parallelism, multi-node pipeline parallelism, and prefill/decode disaggregation.

- [Tutorial](tutorial/README.md): Start here for the four hands-on lessons.
- [Slides](https://suraj.io/kubecon-na26/): Explore the concepts and interactive simulations.
- [Presentation source](presentation/README.md): Run or build the Slidev deck locally.
- [Tests](tests/README.md): Run local tests and live deployment checks.

The lessons assume a preconfigured workshop environment with GPU access and shared model storage. See the [tutorial setup](tutorial/README.md#workspace) for details.
